# Alok Interior — Website Starter

A responsive, premium-style website for Alok Interior using HTML, CSS and JavaScript.

## Included
- `index.html` — page content and sections
- `style.css` — responsive layout and styling
- `script.js` — mobile menu, scroll reveal, WhatsApp contact form
- `assets/alok-singh.png` — photo supplied for the website

## Preview locally
1. Extract this folder.
2. Open `index.html` in a modern browser. For best results, use VS Code with the Live Server extension.
3. Internet is required for Google Fonts and the remote sample interior photographs.

## Contact details
Both the call button and WhatsApp links use `+91 73796 82425`.

## Publish using GitHub Pages
1. Open the GitHub repository where you want the website.
2. Upload the contents of this folder (not the ZIP file itself) to the repository root.
3. Make sure `index.html`, `style.css`, `script.js`, and the `assets` folder are at the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select your main branch and `/ (root)`, then Save.
6. After GitHub Pages finishes deploying, open the URL shown on the Pages settings screen.

## Connect alokinterior.in
In the DNS settings at the domain provider, add the DNS records recommended by GitHub Pages for your repository. In GitHub **Settings → Pages**, enter `alokinterior.in` as the custom domain and follow the verification instructions. Enable HTTPS once it becomes available. DNS changes can take time to propagate.

## Before going live
- Replace the inspiration/sample interior images with genuine project photos or properly licensed images.
- Confirm the business address, service area, business hours, and social links before adding them.
- The contact form opens a WhatsApp message; it does not store submissions in a database.
- Check the domain's current DNS/hosting configuration before changing records, so the existing site is not interrupted.
